# Branco Som — landing page

Versão revisada com CSS próprio, sem dependência das classes utilitárias do Tailwind.

## Melhorias
- CSS organizado por tokens, layout, componentes e responsividade.
- Remoção da duplicidade entre `tailwind.css` e `styles.css`.
- HTML semântico e acessível.
- Menu mobile com `aria-expanded`, `Escape` e fechamento ao redimensionar.
- `defer` no JavaScript.
- Imagens não críticas com `loading="lazy"`.
- Melhor foco de teclado e suporte a `prefers-reduced-motion`.
- Layout responsivo sem classes utilitárias quebradas.
